# Glacier Glide

A minimal Minecraft mod for NeoForge 1.21.1 that lets boats glide from water onto ice blocks.

## Feature

In vanilla Minecraft, boats can't climb up a one-block step, so they get stuck against the edge of an ice sheet. This mod adds a gentle lift so that when you're rowing a boat in water toward ice, the boat smoothly rises and slides up onto the ice — no more jumping or getting stuck.

- Only triggers when you're holding the forward key (rowing)
- Smooth climb that doesn't "leap" onto the ice

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.233

## Build

```bash
./gradlew build
```

The built jar will be in `build/libs/`.
